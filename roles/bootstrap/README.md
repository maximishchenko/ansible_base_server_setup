# Base server setup. Bootstrap

## Инициализация окружения для станции управления:

### Создание пользователя для станции управления Ansible

- Обновление список пакетов в репозиториях;
- Обновление список установленных пакетов;
- Очистка устаревших пакетов;
- Установка утилиты `sudo`;

> [!WARNING]
> При реализации необходимо учитывать потребность установки пакета `sudo`
> в зависимости от используемого дистрибутива
> Например в Debian утилита `sudo` не включена в состав дистрибутива.

- Создание группы, члены которой будут иметь право подключения по протоколу `SSH` (по-умолчанию - `ssh_users`);
- Создание пользователя для станции управления Ansible (по-умолчанию - `deploy`), установка пароля, создание домашнего каталога;
- Добавление пользователя в группу `sudo` и группу, созданную для разрешения подключения по протоколу `SSH`;
- Добавление публичной части `SSH` ключа для подключения пользователя;

### Настройка параметров безопасности SSH

- Настройка параметров безопасности сервера `SSH`.
- Ограничить доступ только членам определенной группы
- Разрешение подключения только по `SSH` ключам;
- Запрет авторизации пользователя `root`.

### Базовые настройки

- Установка значения `hostname`;
- Установка пароля пользователя `root`;
- Настройка синхронизации времени по протоколу `NTP`;
- Настройка параметров локализации.


### Перечень используемых переменных

| Название переменной | Описание | Обязательная | Значение по умолчанию | Vault | Комментарий |
| :---         | :---         |     :---:      |     :---:      | :---         | :---         |
| `vault_ansible_user`   | Пользователь с правами подключения по `SSH` и правами администратора | Да | Нет    | Да    | В случае если для разных хостов используются разные доступы - расположить на уровне `host_vars` для каждого хоста |
| `vault_ansible_password` | Пароль пользователя для подключения по `SSH` | Да | Нет    | Да    | В случае если для разных хостов используются разные доступы - расположить на уровне `host_vars` для каждого хоста |
| `bootstrap_ssh_users_group_name` | Название группы, члены которой имеют право подключения по `SSH` | Нет | `ssh_users`    | Нет    | Возможно расположить на уровне `group_vars` для групп хостов |
| `vault_bootstrap_deploy_user` | Имя пользователя с правами подключения по `SSH` для дальнейшего использования средствами `Ansible management station`  | Нет | `deploy`    | Да    | Возможно расположить на уровне `group_vars` для групп хостов |
| `vault_bootstrap_deploy_user_password_hash`   | Пароль пользователя `Ansible management station` | Да | Нет    | Да    | Пароль указывается в открытом виде. Шифруется средствами vault. Возможно расположить на уровне `group_vars` для групп хостов |
| `bootstrap_deploy_user_ssh_key_file` | Путь к файлу публичного ключа пользователя `Ansible management station` | Да | Нет    | Нет    | Желательно добавлять файлы в каталог 'files' в корне плейбука. Возможно расположить на уровне `group_vars` для групп хостов |
| `bootstrap_unique_server_hostname` | Имя хоста для установки | Нет | Нет    | Нет    | Значение переменной не указано, но в случае отсутствия будет сгенерировано имя хоста на основании IP-адреса |
| `bootstrap_root_password_hash` | Новый пароль пользователя `root` | Да | Нет    | Нет    | Пароль указывается в открытом виде. Шифруется средствами vault. Возможно расположить на уровне `host_vars` для групп хостов |
| `bootstrap_system_timezone` | Часовой пояс | Да | `UTC`    | Нет    | Возможно расположить на уровне `group_vars` для групп хостов |
| `bootstrap_timesyncd_ntp_servers` | Список NTP-серверов (YAML-список) | Нет | `["0.pool.ntp.org", "1.pool.ntp.org"]`    | Нет    | Возможно расположить на уровне `group_vars` для групп хостов |
| `bootstrap_timesyncd_fallback_servers` | Список резервных NTP-серверов (YAML-список) | Нет | `["2.pool.ntp.org", "3.pool.ntp.org"]`    | Нет    | Возможно расположить на уровне `group_vars` для групп хостов |
| `bootstrap_system_locales` | Список системных локалей (YAML-список) | Нет | `["en_US.UTF-8 UTF-8", "ru_RU.UTF-8 UTF-8"]`    | Нет    | Возможно расположить на уровне `group_vars` для групп хостов |
| `bootstrap_system_default_locale` | Системная локализация по умолчанию (YAML-список) | Нет | `["ru_RU.UTF-8 UTF-8"]`    | Нет    | Возможно расположить на уровне `group_vars` для групп хостов |
